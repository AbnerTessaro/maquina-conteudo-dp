# Máquina de Conteúdo DP

## Objetivo
Sistema automatizado em Python que coleta notícias de DP/RH, usa Claude API pra curar as melhores pautas, salva num kanban no Notion, e gera rascunhos de posts para redes sociais.

## Stack
- Python 3.11+
- Claude API
- Notion API
- feedparser
- requests
- python-dotenv
